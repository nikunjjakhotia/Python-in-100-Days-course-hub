# Week 02 Assignment: Build a Text-Based Adventure Game

**Days 8–14 · Topics: if/elif/else, Comparison Operators, while, for, break/continue, List Comprehensions**

Using the control flow concepts from Days 8–14, build a short interactive CLI adventure game with branching paths and a score tracker.

## What to Build
- At least 3 branching story scenes using `if/elif/else`
- A `while` loop that keeps the game running until the player wins, loses, or quits
- A health or score tracker that updates based on the player's choices
- A `for` loop that displays a summary of all choices made at the end of the game
- At least one list comprehension (e.g. filter available actions, calculate a leaderboard)

# Week 02 Assignments — Control Flow

**Days 8–14 · Topics: if/elif/else, Comparison Operators, while, for, break/continue, List Comprehensions**

---

## Assignments

### Day 08 — if / elif / else
- Write a grade classifier: A (90+), B (80–89), C (70–79), D (60–69), F (<60)
- Build a simple login system with 3 attempts before lockout
- Write a leap year checker

### Day 09 — Comparison & Logical Operators
- Write a password validator: min 8 chars, contains a digit, contains uppercase
- Build a BMI calculator with health-category output (Underweight / Normal / Overweight / Obese)
- Implement FizzBuzz for 1–100

### Day 10 — while Loops
- Write a countdown timer that prints from N to 0
- Build a "guess the number" game using a while loop (give hint: too high / too low)
- Write a while loop that collects names until the user types "done"

### Day 11 — for Loops & range()
- Print multiplication tables for 2 through 12
- Sum all odd numbers between 1 and 100 using a for loop
- Reverse a list without using `.reverse()` or slicing

### Day 12 — break, continue & Loop Patterns
- Find the first prime number greater than N
- Print a right-angle triangle of `*` characters with height N
- Write a loop that skips multiples of 3

### Day 13 — List Comprehensions
- Use a comprehension to square all even numbers in a list
- Extract email addresses from a list of user dicts
- Flatten a 2-D list into a 1-D list using a comprehension

### Day 14 — Project: Number Guessing Game
- Add difficulty levels: Easy (10 tries), Medium (7), Hard (5)
- Track the player's score across multiple rounds
- Save the high score to a file

# Week 03 Assignment: Build a Multi-Function CLI Toolkit

**Days 15–21 · Topics: Functions, Parameters, *args/**kwargs, Scope, Lambda, Recursion**

Using the function concepts from Days 15–21, build a CLI toolkit with three independent tools — a unit converter, a calculator with history, and a text analyser — all navigated from a single menu.

## What to Build
- Unit converter: clean functions for length, weight, and temperature using default parameters
- Calculator: supports `+`, `-`, `*`, `/`, `%`, and `**`; stores the last 10 operations in a list
- Text analyser: word count, sentence count, and most common word — using `lambda` and `sorted()`
- A top-level `main()` with a `while` loop menu to navigate between the three tools
- At least one recursive function (e.g. recursive factorial or power used inside the calculator)

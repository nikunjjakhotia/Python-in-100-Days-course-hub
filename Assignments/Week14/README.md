# Week 14 Assignments — Career & Portfolio

**Days 92–100 · Resume, GitHub, Interviews, Deployment**

---

## Overview

This final week is about presenting your skills to the world. The assignments are less code-heavy and more career-focused — the outputs are real artefacts you'll use in job applications.

---

## Assignments

### Day 92 — Resume
- Draft (or update) your Python developer resume using the template from the lesson
- Write 3 project bullet points using the "action + what + tech + outcome" format
- Share it for peer review in the LinkedIn course group

### Day 93 — GitHub Profile
- Create or update your GitHub profile README (`username/username` repo)
- Write at least 3 well-named, properly READMEd repositories on your profile
- Apply conventional commit messages to all new commits going forward

### Day 94 — Portfolio Projects
- Score your capstone against the depth checklist (Day 94 lesson)
- Write a 1-page case study for your capstone (problem, solution, tech, challenge, result)
- Identify 2 more exercises from this course to expand into portfolio projects

### Day 95 — Open Source
- Find a beginner-friendly issue on a Python project you use or admire
- Fork the repo and make one meaningful contribution (docs, test, or small fix)
- Open a pull request with a proper description

### Day 96–98 — Interview Prep
- Solve 5 data structure problems (Day 96) in a timed 45-minute session
- Solve 3 algorithm problems (Day 97) and explain the time complexity of each
- Give OOP explanations (Day 98) of encapsulation, inheritance, polymorphism — out loud or in writing

### Day 99 — Deployment
- Deploy your capstone (or Week 10 Flask app) to Render or Railway
- Share the live URL in the LinkedIn course group
- Confirm `debug=False`, no secrets in code, and HTTPS enabled

### Day 100 — Wrap-Up
- Complete the self-assessment scorecard (Day 100 exercises)
- Post a LinkedIn update announcing your course completion with:
  - What you built
  - What was hardest
  - What you're building next
  - Tag `#PythonIn100Days` and `@nikunjjakhotia`

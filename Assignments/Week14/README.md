# Week 14 Assignment — Portfolio README & Project Showcase

**Days 92–100 · Topics: Resume, GitHub Profile, Open Source, Interview Prep, Deployment**

Your final deliverable: a polished GitHub profile, three deployed or documented projects, and a public announcement of your course completion.

---

## 🎯 What You'll Build

Real career artefacts — not exercises — that you will use in job applications: a GitHub profile README, deployed projects, and an open-source contribution.

---

## 📋 Requirements

1. **GitHub profile README** (`username/username` repo): write a `README.md` with a one-paragraph intro, a "Tech Stack" badges section, your top 3 projects with descriptions and links, and a "Currently Learning" section.
2. **Deploy your capstone** to [Render](https://render.com/) or [Railway](https://railway.app/) — confirm `debug=False`, confirm HTTPS is active, and include the live URL in your project README.
3. **Project showcase card for 3 projects** — for each one, write a `showcase.md` (or update the project's own README) with: what problem it solves, the key technical challenge you overcame, the tech stack, and a screenshot or demo GIF.
4. **Open-source contribution:** find a beginner-friendly issue (`good first issue` label) on any public repo, fork it, make a meaningful change (docs fix, test, small bug fix), and open a pull request — paste the PR URL in your submission.
5. **LinkedIn post:** write a 150–200 word post announcing course completion — what you built, what was hardest, what you are building next — tag `#Python100Days` and `@nikunjjakhotia`.
6. **Self-assessment scorecard** (from Day 100 exercises): rate your confidence 1–5 in each of the 14 weekly topics and identify your top 2 areas for continued growth.
7. **Interview prep summary:** write 5 technical questions you could now answer confidently and 5 that you want to study further — with a one-sentence answer for each confident question.
8. **`requirements.txt`** for every deployed project — all dependencies pinned with exact versions (`pip freeze > requirements.txt`).

---

## 💡 Hints

- GitHub profile README: create a repo with the exact same name as your username — the `README.md` appears on your profile page.
- Render free tier: add a `render.yaml` or configure via the dashboard — set `startCommand: gunicorn app:app`.
- `shields.io` badges: `![Python](https://img.shields.io/badge/Python-3.12-blue)` — swap in your versions.
- Search GitHub for `label:"good first issue" language:python is:open` to find contribution opportunities.

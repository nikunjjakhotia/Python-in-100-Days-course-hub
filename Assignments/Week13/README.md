# Week 13 Assignment: Build Your Capstone Project

**Days 85–91 · Topics: Architecture, Scaffolding, CRUD, Testing, Documentation, Code Review**

Using everything learned across the course, design and build a complete Python project of your choice that demonstrates real-world software skills.

## What to Build
- A working app that integrates **at least 3** of: SQLite database, Flask web interface or rich CLI, external API, file automation, pandas analysis, or unit tests
- A written spec submitted on Day 85: problem statement, target user, 3–5 core features, data model sketch, and technology choices with justification
- At least **8 unit tests** using `unittest`, including 2 database tests against an in-memory SQLite
- A `README.md` with: title, problem description, features list, Quick Start steps, project structure, and technologies used
- A `requirements.txt` and a clean `git log` with conventional commit messages throughout the week

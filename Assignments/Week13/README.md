# Week 13 Assignments — Capstone Project

**Days 85–91 · Build and polish your end-to-end Python project**

---

## Overview

This week you build and ship a complete Python project of your choice. It must integrate at least **3 of the following**:

- SQLite database (CRUD)
- REST API or web scraping
- Flask web interface OR rich CLI
- pandas / data analysis
- Automation (file system, scheduling, or email)
- Unit tests (`unittest`)

---

## Deliverables

### Day 85 — Spec Document
Submit a written spec answering:
1. Problem statement (1–2 sentences)
2. Target user / use case
3. 3–5 core features (bullet list)
4. Data model sketch (tables + key fields)
5. Technology choices with justification

### Day 86 — Scaffold
- Working directory structure with all files created (even if empty)
- Database schema applied and seeded
- Entry point runs without errors

### Day 87 — Feature 1
- First core feature working end-to-end
- Basic input validation present

### Day 88 — Feature 2 + Menu
- Second core feature working
- Interactive CLI menu (or Flask routes) connecting all features

### Day 89 — Tests
- At least 8 unit tests covering core business logic
- At least 2 database tests using an in-memory SQLite

### Day 90 — Documentation
- `README.md` with: title, problem, features, Quick Start, project structure, technologies
- Docstrings on every public function
- `requirements.txt` present

### Day 91 — Polish
- Self-review checklist completed (see Day 91 lesson)
- Edge cases handled
- No SQL injection vulnerabilities
- `git log` shows clean, conventional commit messages

---

## Grading Criteria

| Criteria | Points |
|----------|--------|
| Spec quality and adherence | 10 |
| Features work end-to-end | 35 |
| Test coverage (≥ 8 tests) | 20 |
| README and docstrings | 20 |
| Code quality (no SQL injection, clean structure) | 15 |
| **Total** | **100** |

# Week 01 Assignment: Build a Personal Bio App

**Days 1–7 · Topics: Variables, Data Types, Strings, Lists, Dicts, Sets, Type Conversion**

Using everything from Days 1–7 — variables, data types, strings, lists, dictionaries, and `input()` — build a CLI app that asks the user a series of questions and prints a neatly formatted bio card.

## What to Build
- Prompt for name, age, city, top 3 hobbies (stored in a list), and 3 skills with a self-rating 1–5 (stored in a dict)
- Validate that age is a positive integer — re-prompt if the input is invalid
- Display a formatted bio card using f-strings that shows all the collected information
- Use a set to de-duplicate the hobbies list and display unique interests
- End with a personalised closing line that uses the user's name

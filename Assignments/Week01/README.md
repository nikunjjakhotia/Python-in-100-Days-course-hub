# Week 01 Assignments — Python Fundamentals

**Days 1–7 · Topics: Variables, Data Types, Strings, Lists, Dicts, Sets, Type Conversion**

---

## How to Submit

Complete the assignment files in this folder and push your work to GitHub. Share the link in the LinkedIn post for the relevant day.

---

## Assignments

### Day 01 — Introduction to Python & Setup
`Day01Assignments.py`
- Install Python and VS Code; confirm `python --version` works
- Run a "Hello, World!" script
- Print your name, age, and favourite programming language

### Day 02 — Variables & Data Types
`Day02Assignments.py`
- Declare variables for name (str), age (int), height (float), and is_student (bool)
- Print each variable and its type using `type()`
- Take user input for a name and greet them

### Day 03 — Strings
`Day03Assignment.py`
- Reverse a string entered by the user
- Count vowels in a sentence
- Build a title-case formatter that handles extra whitespace

### Day 04 — Lists & Tuples
`Day04Assignment.py`
- Create a shopping list; add, remove, and sort items
- Find the max and min of a list of numbers without using `max()`/`min()`
- Convert a tuple of coordinates to a list and append a new coordinate

### Day 05 — Dictionaries & Sets
- Build a word frequency counter for a paragraph of text
- Find the intersection and difference of two sets of skills
- Create a phone book dict with add/lookup/delete operations

### Day 06 — Type Conversion & Input Validation
- Write a safe `to_int(value)` function that returns `None` instead of crashing
- Build a temperature converter (°C ↔ °F) with validated input
- Validate an email address (must contain `@` and `.`)

### Day 07 — Project: Contact Book
- Extend the Day 07 project: add a "search by phone number" feature
- Add input validation so empty names are rejected
- Save and load contacts from a `contacts.json` file

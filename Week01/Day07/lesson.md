# Day 07 – Project: My Bio App

## What You're Building
A command-line Bio App that collects personal details from the user and prints a clean, formatted bio card. This project ties together everything from Week 1: variables, data types, user input, type casting, and f-string formatting.

---

## Learning Objectives
- Apply Week 1 concepts in a real mini-project
- Practice gathering and validating user input
- Format output in a readable, professional style

---

## Project Spec

### Inputs to collect:
| Field | Type |
|---|---|
| Full name | string |
| Age | integer (cast from input) |
| City | string |
| Favorite hobby | string |
| Fun fact | string |
| Favorite number | integer (used for a bonus calculation) |

### Expected Output:
```
╔══════════════════════════════════════╗
         MY BIO CARD
╚══════════════════════════════════════╝
Name    : Nikunj Jakhotia
Age     : 34
City    : Montreal
Hobby   : Swimming
Fun Fact: I've visited 10 countries!
Lucky # : 7  →  Doubled: 14
```

---

## Skills Used
- `input()` — collecting user data
- `int()` — type casting
- f-strings — formatted output
- Variables and data types

---

## Starter Code
See `exercises.py` for the full project code.

---

## Bonus Challenges
1. Add a second hobby and print both with a comma separator.
2. Display the user's birth year by calculating `2025 - age`.
3. Add a simple ASCII border around the output.

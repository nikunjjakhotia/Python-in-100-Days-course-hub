# Day 92 – Writing a Python Developer Resume

## Learning Objectives
- Know what hiring managers look for in a Python developer CV
- Structure your resume for both human and ATS (Applicant Tracking System) review
- Write achievement-based bullet points for projects

---

## Resume Structure

```
[Name]  |  City  |  Phone  |  Email  |  GitHub  |  LinkedIn

SUMMARY
Two sentences: who you are + what you're looking for.

SKILLS
Languages: Python (primary), SQL, JavaScript
Frameworks: Flask, pandas, requests, BeautifulSoup
Tools: Git, SQLite, VS Code, Linux/macOS
Concepts: REST APIs, OOP, Testing (unittest), Data Analysis

PROJECTS
1. Expense Tracker — Python, SQLite, CLI
   • Built a full CRUD CLI app with SQLite backend; validates all inputs and 
     produces monthly category summaries.
   • github.com/you/expense-tracker

2. Weather Dashboard — Python, requests, Open-Meteo API
   • Fetches live forecasts for any city using REST API + Nominatim geocoding.
   • github.com/you/weather-dashboard

EXPERIENCE
[Your previous roles, if any]

EDUCATION
[Degree / course / self-taught]
Python in 100 Days — Online course (2026)
```

---

## Achievement-Based Bullets

**Weak:**  "Made a to-do app with SQLite"

**Strong:**  "Built a persistent CLI to-do app using Python + SQLite; supports full CRUD, timestamps, and CSV export — used daily to manage my own tasks"

Use the format: **[action verb] + [what you built] + [technical detail] + [outcome/impact]**

---

## ATS Keywords for Python Roles

Include these where truthful:
`Python`, `SQL`, `REST API`, `Git`, `Flask`, `pandas`, `OOP`, `unit testing`, `data analysis`, `web scraping`, `automation`

---

## Key Takeaways
- Tailor the skills section to match the job description's exact keywords
- Each project bullet should answer "so what?" — what problem did it solve?
- Keep it to one page until you have 5+ years of experience
